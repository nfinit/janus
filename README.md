JANUS
-----------------------------------------------------------------
*A universal minimal agent gateway for modern and legacy systems*

## Introduction
JANUS is an experimental harness that allows you to instantiate agents on any system capable producing a shell through SSH or Telnet, with agent personality and purpose determined through up-front user specification or progressively through system discovery and collaboration. 

This repository is currently a stub as JANUS is being re-defined and rewritten according to new principles and targets, the old Phase 0 code has been moved to [janus-archive](https://github.com/nfinit/janus-archive/).
